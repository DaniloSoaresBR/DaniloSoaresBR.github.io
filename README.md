# DaniloSoaresBR.github.io

Portfólio pessoal de Danilo Soares da Silva, em português (`/`) e inglês (`/en/`).

Construído com [Astro](https://astro.build). Conteúdo em `src/data/content.ts`.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

O deploy é feito pelo workflow `.github/workflows/deploy.yml` a cada push na `main`, publicando no GitHub Pages.
